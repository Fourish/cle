# 膜体系分子动力学

本步骤使用 OpenMM 对环肽–受体–G 蛋白膜体系进行能量最小化、预设平衡及生产模拟。输入为 CHARMM-GUI 参数化的完整体系，体系化学态见 [项目说明](../../README.md)。

仓库保留模拟源码，E07–E11 的大型膜体系数据需另行准备。将各体系完整的 CHARMM-GUI 目录放入 `data/<体系编号>/charmm-gui-result/`，脚本从其中的 `openmm/` 目录读取输入；这五个数据目录不纳入版本管理。

## 模拟流程

| 阶段 | 内容 |
|---|---|
| 6.1 | 能量最小化与 125 ps 初始平衡 |
| 6.2–6.6 | 后续平衡阶段，六段预设平衡总时长为 1.875 ns |
| 7 | 从平衡末态启动 100 ns 生产模拟 |

## 生产参数

| 参数 | 设置 |
|---|---|
| 时间步长 | 2 fs |
| 温度 | 300 K |
| 压力 | 1 bar |
| 静电相互作用 | PME |
| 范德华相互作用 | Force-switch，切换区间 1.0–1.2 nm |
| 键约束 | 涉及氢原子的共价键长约束 |
| 轨迹保存间隔 | 10 ps |

输出为模拟轨迹、末态结构和能量、温度等观测信息。

## 使用

准备好输入后，在项目根目录按体系编号和阶段执行：

```bash
bash src/md_utils/run.sh E07 6.1
```

按 6.1–6.6、7 的顺序执行；E08–E11 替换体系编号。体系输入位于 `data/`，模拟输出位于 `result/`。
