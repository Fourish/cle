# 复合物几何筛选与代表选择

流程以受体结构和含氢环肽构象为输入，依次进行批量对接、完整复合物几何筛选、组内聚类及代表模型生成。

## 几何筛选

| 项目 | 默认条件 |
|---|---|
| 化学身份 | 保持分子图、立体化学、闭环连接与酰胺顺反状态 |
| 环肽内部几何 | 键长、酰胺几何及非键接触符合筛选要求 |
| 受体碰撞 | 最短重原子距离 ≥1.8 Å，vdW 距离比 ≥0.75 |
| 环肽内部碰撞 | 非键重原子对的 vdW 距离比 ≥0.75；排除最短拓扑距离 ≤3 的原子对 |
| 潜在穿环 | 受体主链键与环肽主链质心扇面无交点产生的潜在穿环标记 |
| 目标链接触 | 4 Å 内至少接触 3 个目标链残基，涉及至少 8 个环肽重原子 |

碰撞筛查覆盖全部保留受体组分；目标链接触默认仅以 R 链计数。vdW 距离比为原子间距离与两原子 vdW 半径之和的比值。

## 聚类与代表选择

仅在同一环肽、受体模型及搜索条件内聚类。受体坐标系中的主链直接 RMSD 阈值为 3 Å，接触残基集合 Jaccard 相似度阈值为 0.5。

代表选择优先考虑独立种子和来源构象的支持，再按组内 Vina 评分排序，每组最多选择 3 个代表。姿态保持受体坐标系，不另行叠合。

## 产物

产物包括重原子复合物 PDB、环肽 SDF、几何指标及来源信息。复合物保留受体组分和环肽连接关系，SDF 保存分子图与立体化学。

候选用于后续参数化和建膜。建膜须提供环肽命名、闭环连接、质子化状态及力场参数。

## 使用

完整执行环肽准备、受体准备和对接筛选：

```bash
bash generate_models.sh
```

仅对已准备构象和受体执行对接与筛选：

```bash
python src/0003-binding-site-selection/run_pipeline.py \
  --config src/profiles/docking_8xql.json \
  --output-dir work/docking_8xql
```
